# IFCD0062 · Fundamentos de programación en Python · Recursos del libro

Material complementario del libro *Fundamentos de programación en Python*, que desarrolla la
especialidad formativa IFCD0062. Cada código QR del libro lleva a uno de estos recursos:

| Tipo | Qué es |
|---|---|
| Ejecuta | Cuaderno de Python que se ejecuta en el navegador (JupyterLite), sin instalar nada |
| Explora | Herramienta interactiva para experimentar con un concepto |
| Compruébalo | Test de autoevaluación con la explicación de cada respuesta |

Web: https://python-formacion.github.io/ifcd0062/

- `recursos.csv`: tabla única de códigos QR (código, tipo, título y destino).
- `contenido/notebooks/`: cuadernos y datos de cada unidad (cada carpeta con datos tiene su
  `LEEME.md` con la fuente y la licencia).
- `contenido/recursos/`: exploradores y tests.
- `herramientas/construir.py`: construye la web en `site/`.
- `.github/workflows/pages.yml`: ejecuta todos los cuadernos con Python 3.14 y publica la
  web en GitHub Pages.

Este repositorio no es un sitio oficial del SEPE ni de FUNDAE. Ninguna página pide registro,
usa cookies ni envía datos de quien la visita.
